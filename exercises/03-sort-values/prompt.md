title: Sort and take the top
topic: sorting
difficulty: easy
data: orders.csv

Find the 5 order lines with the highest `unit_price`.

- Sort by `unit_price`, highest first. If two lines have the same price, the lower `order_id` comes first.
- Keep only the 5 first rows and the columns `order_id`, `product`, `unit_price`.
